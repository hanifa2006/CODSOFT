# Task 2 – CODSOFT Internship  
## Tic Tac Toe Game

## Description
This project is a **Tic Tac Toe game** developed as **Task 2** of the **CODSOFT Internship**.  
The game allows two players to play Tic Tac Toe using a simple and interactive interface.  
It checks for winning conditions, draw situations, and ensures valid player moves.

## Technologies Used
- **Python**

## Features
- Two-player gameplay  
- Turn-based system (Player X and Player O)  
- Automatic win detection  
- Draw detection  
- User-friendly and simple logic  

## How to Run
1. Ensure **Python 3** is installed on your system.
2. Clone or download the repository.
3. Navigate to the project directory.
4. Run the following command:

```bash
python tic_tac_toe.py
