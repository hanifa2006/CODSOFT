# Task 1 – CODSOFT Internship  
## Rule-Based Chatbot

## Description
This project is a **Rule-Based Chatbot** developed as **Task 1** of the **CODSOFT Internship**.  
The chatbot interacts with users by matching predefined rules and keywords and responds accordingly.  
It is designed to handle basic conversations such as greetings, help requests, personal questions, and exit commands.

## Technologies Used
- **Python**
- Standard Python Library (`random`)

## Features
- Responds to greetings and farewells  
- Answers basic user queries  
- Provides random responses for natural interaction  
- Simple and beginner-friendly implementation  
- Runs in command-line interface (CLI)

## How to Run
1. Make sure **Python 3** is installed on your system.
2. Download or clone the repository.
3. Navigate to the project folder.
4. Run the following command:

```bash
python chatbot.py
